# Runtime Vs Declared State

Declared infrastructure state does not always match:
- runtime infrastructure reality.

Infrastructure observability helps identify:
- operational divergence between both states.

---

# Why This Matters

Terraform manages:
- intended infrastructure state.

But runtime environments may still experience:
- drift
- manual modification
- or operational inconsistency.

---

# Operational Risks

Differences between:
- declared state
and:
- runtime state

may create:
- deployment unpredictability
- recovery difficulty
- and debugging complexity.

---

# Governance Connection

Services such as:
- AWS Config
- and CloudTrail

help observe:
- runtime infrastructure behavior.

---

# Platform Engineering Perspective

Operational consistency requires visibility into:
- both intended and runtime infrastructure state.

---

# Key Insight

Infrastructure reliability depends on understanding runtime operational reality.
