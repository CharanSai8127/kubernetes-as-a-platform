# Import And State Reconciliation

Terraform import helps reconnect:
- existing runtime infrastructure
with:
- Terraform state.

---

# Why Import Matters

Resources may become unmanaged due to:
- manual creation
- orphaned infrastructure
- or lost state mappings.

---

# Common Recovery Scenarios

Examples include:
- restoring deleted state
- reconnecting orphaned resources
- importing manually created infrastructure
- and rebuilding missing mappings.

---

# Operational Benefits

State reconciliation improves:
- ownership consistency
- infrastructure visibility
- and deployment predictability.

---

# Platform Engineering Perspective

Infrastructure recovery is part of:
- long-term operational reliability.

---

# Key Insight

Infrastructure recovery frequently requires rebuilding state consistency.
