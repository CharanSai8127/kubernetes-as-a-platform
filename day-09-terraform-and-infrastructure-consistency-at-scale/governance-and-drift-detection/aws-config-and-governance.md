# AWS Config And Governance

AWS Config helps observe:
- runtime infrastructure behavior continuously.

It stores:
- infrastructure configuration history
- resource changes
- and compliance evaluation data.

---

# Why Governance Matters

Terraform manages:
- desired infrastructure state.

But runtime infrastructure may still experience:
- manual drift
- unauthorized changes
- and operational inconsistency.

---

# Operational Benefits

AWS Config improves:
- drift visibility
- compliance evaluation
- auditability
- and operational awareness.

---

# Common Governance Checks

Examples include:
- public S3 detection
- unrestricted security groups
- encryption validation
- and IAM compliance checks.

---

# Platform Engineering Perspective

Governance systems observe:
- runtime infrastructure reality.

Terraform manages:
- intended infrastructure state.

---

# Key Insight

Infrastructure governance improves operational visibility and drift awareness.
