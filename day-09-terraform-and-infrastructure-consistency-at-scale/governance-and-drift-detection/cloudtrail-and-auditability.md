# CloudTrail And Auditability

CloudTrail records:
- infrastructure API activity.

This improves:
- operational auditability
- and drift tracing.

---

# Why Auditability Matters

Infrastructure drift frequently begins through:
- manual API activity
- or uncontrolled infrastructure modification.

CloudTrail helps identify:
- who changed what
- when changes occurred
- and how infrastructure evolved.

---

# Operational Benefits

Audit visibility improves:
- debugging
- compliance
- and infrastructure recovery.

---

# Common Use Cases

Examples include:
- tracing deleted resources
- identifying IAM modifications
- investigating networking changes
- and debugging infrastructure drift.

---

# Platform Engineering Perspective

Infrastructure reliability also depends on:
- operational visibility into runtime changes.

---

# Key Insight

Auditability improves infrastructure ownership and operational accountability.
