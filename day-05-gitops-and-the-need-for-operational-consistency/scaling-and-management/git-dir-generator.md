# git-dir Generator

The git-dir generator dynamically creates Argo CD Applications by iterating across repository directory structures.

This enables scalable declarative environment management inside GitOps platforms.

---

# Why It Matters

Distributed systems frequently contain:
- multiple environments
- overlays
- application tiers
- and operational variations

Managing these environments manually becomes operationally difficult at scale.

The git-dir generator automates:
- discovery
- generation
- and reconciliation

through repository structure.

---

# Declarative Environment Discovery

The generator continuously scans:
- directory structures
- overlays
- and repository layouts

then dynamically creates:
- Application resources
- and reconciliation workflows

inside Kubernetes environments.

---

Environment generation through repository structure improves:
