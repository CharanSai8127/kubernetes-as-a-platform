# What Is Continuous Delivery

Continuous Delivery focuses on:
- controlled deployment readiness.

The primary goal of CD is:
- safely promoting validated artifacts toward production environments.

---

# Core Responsibilities

CD systems commonly manage:
- deployment orchestration
- rollout behavior
- environment promotion
- approval workflows
- rollback handling
- and deployment observability.

---

# Why CD Exists

Even trusted artifacts may still create:
- unstable deployments
- failed rollouts
- dependency issues
- or production outages.

Deployment safety therefore requires:
- operational control.

---

# Deployment Responsibility

CD controls:
- how applications reach environments.

This includes:
- staging
- production
- and multi-environment promotion flows.

---

# Key Insight

CD establishes trust in deployment behavior after CI establishes trust in artifacts.
