# What Is Continuous Integration

Continuous Integration focuses on:
- validating code changes continuously.

The primary responsibility of CI is:
- ensuring the generated artifact is safe, testable, and deployable.

---

# Core Responsibilities

CI pipelines commonly perform:
- build validation
- unit testing
- static analysis
- vulnerability scanning
- dependency validation
- and artifact generation.

---

# Why CI Exists

Modern systems evolve continuously through:
- feature additions
- bug fixes
- dependency updates
- and infrastructure changes.

CI helps detect:
- integration failures
- broken builds
- and security risks early.

---

# Artifact Validation

The final output of CI becomes:
- the deployment artifact.

Examples include:
- container images
- binaries
- packages
- or manifests.

---

# Key Insight

CI establishes trust in artifacts before deployment begins.
