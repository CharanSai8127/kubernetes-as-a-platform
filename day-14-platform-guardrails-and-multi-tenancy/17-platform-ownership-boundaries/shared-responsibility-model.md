# Shared Responsibility Model

Successful platforms operate through:
- shared responsibility.

Not every responsibility belongs to:
- one team.

Some responsibilities require:
- collaboration.

---

# Why Shared Responsibility Matters

Platform operations span:
- infrastructure
- security
- governance
- and applications.

Multiple teams contribute to:
- platform success.

---

# Example Responsibility Model

Platform Team:
- cluster operations
- networking
- governance
- security controls

Application Team:
- application code
- deployment configuration
- application health

---

# Runtime Platform Benefits

Shared responsibility improves:
- accountability
- ownership
- and operational alignment.

---

# Platform Engineering Perspective

Responsibilities should be explicit rather than assumed.

---

# Key Insight

Successful platforms rely on clearly defined shared responsibilities.
