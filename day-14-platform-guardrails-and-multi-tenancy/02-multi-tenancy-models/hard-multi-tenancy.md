# Hard Multi-Tenancy

Hard multi-tenancy provides:
- dedicated infrastructure
for each tenant.

Each tenant commonly receives:
- a dedicated Kubernetes cluster.

---

# Why Hard Multi-Tenancy Matters

Hard isolation improves:
- security
- compliance
- and tenant independence.

---

# Runtime Isolation

Tenants do not share:
- worker nodes
- control planes
- or runtime resources.

This significantly reduces:
- cross-tenant impact.

---

# Operational Challenges

Hard multi-tenancy increases:
- infrastructure cost
- operational complexity
- and management overhead.

---

# Platform Engineering Perspective

Hard multi-tenancy prioritizes:
- isolation over efficiency.

---

# Key Insight

Dedicated infrastructure provides the strongest tenant isolation model.
