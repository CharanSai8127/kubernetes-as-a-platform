# Security Guardrails Overview

Security guardrails protect:
- workloads
- platform components
- infrastructure
- and tenant boundaries.

Guardrails establish:
- minimum security requirements for the platform.

---

# Why Security Guardrails Matter

Applications are not always:
- secure
- correctly configured
- or trusted.

The platform must assume:
- workloads can become compromised.

---

# Security Goals

Security guardrails aim to provide:
- least privilege
- workload isolation
- attack surface reduction
- and platform protection.

---

# Runtime Platform Protection

Security guardrails reduce:
- privilege escalation
- lateral movement
- and platform compromise.

---

# Platform Engineering Perspective

Security should be enforced by the platform rather than relying solely on developers.

---

# Key Insight

Secure platforms assume failures and compromises will eventually occur.
