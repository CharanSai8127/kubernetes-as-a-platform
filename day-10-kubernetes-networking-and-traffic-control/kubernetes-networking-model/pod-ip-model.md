# Pod IP Model

Every Kubernetes pod receives:
- its own unique IP address.

Applications communicate through:
- pod-level networking identities.

---

# Why Pod IPs Matter

Pod IP allocation enables:
- direct workload communication.

This improves:
- service discovery
- runtime routing
- and communication consistency.

---

# Runtime Communication

Distributed workloads depend on:
- reliable pod-level reachability.

---

# Operational Challenges

Scaling increases:
- routing complexity
- endpoint management
- and communication pressure.

---

# Platform Engineering Perspective

Pod-level networking directly impacts:
- runtime traffic behavior.
