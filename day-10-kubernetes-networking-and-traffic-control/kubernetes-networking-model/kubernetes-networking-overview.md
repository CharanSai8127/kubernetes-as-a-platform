# Kubernetes Networking Overview

Kubernetes uses:
- a flat networking model.

Every pod receives:
- its own routable IP address.

---

# Core Communication Model

Kubernetes enables:
- pod-to-pod communication
without:
- network address translation between pods.

---

# Why This Matters

Applications communicate directly across:
- nodes
- namespaces
- and workloads.

Networking therefore becomes:
- distributed-system communication infrastructure.

---

# Operational Importance

Kubernetes networking impacts:
- service discovery
- traffic flow
- runtime communication
- and failure propagation.

---

# Platform Engineering Perspective

Networking reliability becomes critical for:
- runtime survivability at scale.

---

# Key Insight

Kubernetes networking enables distributed-system communication consistency.
