# Storage Locality

Storage locality focuses on:
- keeping workloads close to their storage.

Stateful systems continuously depend on:
- low-latency storage communication.

---

# Why Locality Matters

Improper storage locality may create:
- increased latency
- delayed synchronization
- and degraded runtime performance.

---

# Runtime Communication

Database workloads continuously exchange:
- read operations
- write operations
- replication traffic
- and synchronization updates.

---

# Operational Challenges

Cross-zone or remote storage access may create:
- communication amplification
- slower queries
- and runtime instability.

---

# Platform Engineering Perspective

Storage locality strongly impacts:
- runtime communication survivability.

---

# Key Insight

Database pod proximity to storage directly impacts runtime latency.
