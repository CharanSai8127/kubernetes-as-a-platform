# Requests Vs Limits

Kubernetes workloads define:
- requests
- and limits.

Requests reserve:
- infrastructure capacity.

Limits restrict:
- maximum runtime resource usage.

---

# Why Requests And Limits Matter

Improper values create:
- infrastructure waste
- runtime instability
- and scheduling inefficiency.

Oversized requests increase:
- unused infrastructure reservation.

Undersized limits increase:
- runtime throttling
- and application instability.

---

# Runtime Infrastructure Coordination

Kubernetes continuously schedules workloads based on:
- requested CPU
- and memory allocation.

Limits protect:
- cluster resource stability.

---

# Operational Challenges

Improper configuration may create:
- noisy neighbors
- fragmented infrastructure
- and unstable scaling behavior.

---

# Platform Engineering Perspective

Requests and limits become:
- runtime infrastructure governance mechanisms.

---

# Key Insight

Incorrect requests create invisible infrastructure cost.
