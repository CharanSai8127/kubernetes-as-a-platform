# Underutilized Nodes

Underutilized nodes are:
- worker nodes consuming cloud cost without fully utilizing runtime capacity.

Examples include:
- low CPU usage
- low memory usage
- and partially empty infrastructure.

---

# Why Underutilization Matters

Cloud providers charge for:
- allocated infrastructure capacity,
not:
- actual workload usefulness.

---

# Runtime Infrastructure Waste

Underutilized nodes commonly appear because of:
- oversized workload requests
- poor scheduling
- fragmented infrastructure
- and idle workloads.

---

# Operational Challenges

Persistent underutilization may create:
- infrastructure sprawl
- increased operational cost
- and inefficient autoscaling behavior.

---

# Platform Engineering Perspective

Underutilization directly impacts:
- infrastructure sustainability.

---

# Key Insight

Partially empty nodes continuously amplify infrastructure economics.
