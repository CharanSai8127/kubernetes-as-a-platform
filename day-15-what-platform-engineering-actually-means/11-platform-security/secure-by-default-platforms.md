# Secure By Default Platforms

Developers should receive:

- secure defaults

without requiring extensive security expertise.

---

# Why Secure Defaults Matter

Security controls are often:

- forgotten
- misconfigured
- or inconsistently applied.

Secure defaults reduce:

- human error.

---

# Common Secure Defaults

Examples include:

- least privilege access
- non-root containers
- encrypted communication
- resource governance
- and policy enforcement.

---

# Platform Benefits

Secure defaults improve:

- compliance
- consistency
- and operational safety.

---

# Platform Engineering Perspective

The safest path should also be the easiest path.

---

# Key Insight

Security should happen automatically whenever possible.
