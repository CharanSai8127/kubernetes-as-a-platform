# Platform Interfaces Vs Platform Implementation

A platform consists of:

- interfaces

and

- implementations.

Users consume:
- interfaces.

Platform teams manage:
- implementations.

---

# Platform Interface Examples

Examples include:

- APIs
- portals
- Git repositories
- templates
- and workflows.

---

# Platform Implementation Examples

Examples include:

- Kubernetes
- cloud infrastructure
- networking
- observability
- and security systems.

---

# Why Separation Matters

Developers should focus on:

- consuming capabilities

while platform teams focus on:

- operating capabilities.

---

# Platform Engineering Perspective

Interfaces should remain stable even when implementations evolve.

---

# Key Insight

Users should consume services, not operational complexity.
