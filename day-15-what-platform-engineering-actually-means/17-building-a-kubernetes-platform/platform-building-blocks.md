# Platform Building Blocks

Modern Kubernetes platforms are composed of multiple layers.

Each layer solves a different problem.

---

# Infrastructure Layer

Provides:

- compute
- networking
- storage
- and cloud resources.

Examples include:

- AWS
- Azure
- GCP
- and on-premises infrastructure.

---

# Platform Layer

Provides:

- Kubernetes
- GitOps
- observability
- security
- governance
- and automation.

---

# Application Layer

Provides:

- business functionality
- APIs
- services
- and customer-facing capabilities.

---

# Platform Engineering Perspective

Platforms integrate multiple layers into a unified experience.

---

# Key Insight

Platforms are ecosystems rather than individual components.
